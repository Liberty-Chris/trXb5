# Antenna panel PCB workspace

Initial geometry is a flat 150 × 150 mm magnetic loop with SMA input, matching network, coarse capacitor footprints and RF trimmer adjustment. No native panel layout or approved turn count exists yet.

Define the loop dimensions, turns, copper, trace spacing, ferrite and mounting clearance from calculations and measurements. Record cable type and length. Keep a disconnectable primary loop. See docs/ARCHITECTURE.md for inactive panel interaction requirements.
