# Current label and physical observations

Chris supplied https://www.amazon.com/dp/B0G36Y8YVK as the current label. The listing and supplied Santek manual identify an EZ Sign 2.9 inch four color display, nominal model SE0290C1, 296 × 128 pixels. Exact unit revision is not yet recorded.

Chris disassembled an electronic paper display and reported a chip marked FMSC with a second line read as 419J0G or 419JOG. No board photograph or pin count was supplied in this thread. The marking belongs in the evidence register as a user observation, not a confirmed IC part number.

FMSC is a concrete research lead associated with batteryless electronic paper NFC controller documentation. Good Display publishes an FMSC development manual and an FM1280 controller reference. FM1280 is a candidate to investigate, not an identification of this chip. The second line has not been decoded and must not be asserted to be a date or lot code without evidence.

Record board photographs, all chip lines, package dimensions, pin count, board revision, antenna dimensions and the display flex markings when available. Preserve the existing display configuration and waveform data during investigation.

The vendor recommends a Sony RC S300 for its Windows software. This is a host reader recommendation and does not identify the silicon inside the label.
