# Development roadmap

| Stage | Output | Completion evidence |
| :--- | :--- | :--- |
| 0. Evidence recovery | Locate prior Santek research and identify physical label | Source paths, capture identifiers and documented unit metadata |
| 1. Reader selection | Reader decision and direct path plan | Protocol support, PA interface assessment and official limits |
| 2. Complete circuit | Native KiCad schematics and exact BOM | Completed PA, RX, selector, interlock, power and host circuits with review |
| 3. Antenna engineering | Panel geometry and tuning model | Calculations, candidate ratings and installed measurement plan |
| 4. PCB implementation | Controller and panel layouts | Footprint review, ERC and DRC reports with justified exceptions |
| 5. Prototype release | Gerbers, drills, assembly data and commissioning instructions | Reviewed manufacturable circuit with provisional RF values identified |
| 6. Bringup | Direct reader and actual display update | Recorded identity, transfer, refresh and camera result |
| 7. Extended RF evaluation | Amplifier and selector qualification | Modulation, RX, thermal and coupling measurements |
| 8. Cavity validation | Coverage map and approved operating envelope | Full refresh success across required product conditions |

Prototype fabrication readiness and demonstrated operating readiness are different states. Publish neither a validated range nor a production release until the corresponding measurements exist.
