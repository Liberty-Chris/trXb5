# Rev A1 reader and bench host

Use **NXP PN5180A0HN/C4E** (12NC 935402703551, SOT618-1 HVQFN40) with a 3.3 V SPI bench host. The owner expects a Raspberry Pi and wants to retain an ESP32 option. The first register probe uses Linux SPI and GPIO. The strongest discriminator is a publicly inspectable PN5180 implementation for both Santek sizes. Revisit the choice if this label fails activation or the downstream receiver cannot recover load modulation. [NXP part](https://www.nxp.com/part/PN5180A0HN), [EZ Sign implementation](https://github.com/JUN-KOBAYASHI/ezsign-nfc-tools)

| Design question | PN5180 | ST25R3916B-AQET |
| --- | --- | --- |
| Type A activation and APDU ownership | SPI with NSS/BUSY handshake. LOAD_RF_CONFIG, SEND_DATA, READ_DATA and IRQ status permit host-controlled RATS and ISO-DEP blocks. External EZ Sign code exercises this path. | Type A framing, SPI FIFO, timers, direct commands and transparent/stream modes offer a viable port. The cited Santek implementation would need another transport. |
| WTX and chaining | Host must negotiate ATS/FSC/FWT, validate block numbers, echo a valid S(WTX) with its multiplier and handle inbound and outbound chaining. | The same ISO-DEP obligations apply with a different host stack. Neither chip's Type A feature list proves a complete Santek update. |
| Direct RF adjustment | Differential TX1/TX2, configurable drive, shaping and dynamic power control. Begin with a fixed low drive on a characterized load. | RFO1/2, dynamic power, shaping and phase/amplitude measurements. AN5592 provides a particularly useful coax reference. |
| Receive path and PA | RXP/RXN AC-coupled, VMID-referenced, AGC. Use balanced pickup of the common output downstream of direct/PA selection. Characterize RX level at the package and sideband SNR. DPC sensing at the transmitter cannot substitute for a PA output measurement. | RFI1/2, AM/PM and I/Q reception, RSSI and phase/amplitude measurements. These aid characterization, but an external PA still needs a separate receive path and protection. |
| Package and rails | 6 mm square, 0.5 mm pitch, 4.10 mm nominal exposed ground pad. VBAT and TVDD 2.7–5.5 V, PVDD 2.7–3.6 V in the 3.3 V domain. Table 124 gives 250 mA maximum recommended TVDD current under the stated thermal conditions. | Active AQET has 32 terminals on a 5 mm UFQFPN. Separate I/O rail. Preserve as fallback. |

The reference header reviewed had SHA-256 `ac423528a5cb39281fd0e4fccbfc652b04973bff5f3ad86d2030efd856f94d4c`. Its exchange routine echoes WTX with a fixed per-call timeout, and its APDU path rejects chained responses. Its reactivation routine resets the reader. An unattended write therefore needs a different treatment for negotiated waits, response assembly and field continuity. Lost polling after an accepted refresh leaves completion unknown. The external report that an image may still appear is a reason to collect camera evidence separately.

First collect a read-only identity record with one physically identified label and a direct antenna. Keep the PA unpowered. Capture the reader versions, UID/ATS, device-info response and scope trace showing the field. Authorize image operations only after the profile matches the physical unit. A complete test needs transfer acknowledgement, explicit refresh completion and a camera observation for that same job.
